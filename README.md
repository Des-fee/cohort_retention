Цель: узнать как часто покупатели возвращаются после 1 покупки. Данные: британский онлайн-магазин подарочных товаров, клиенты в основном оптовики, период с 01.12.2010 по 09.12.2011. Когорта это месяц 1 покупки, для каждой когорты считаем сколько клиентов совершили покупки через 1,2,3,4... месяцев

Удержание на первый месяц около 20%. Доля вернувшихся не падает, а к концу года растет. Ну и есть сезонность, самый высокий у всех в ноябре: перед Рождеством оптовики закупают подарочные товары. Рекомендации стимулировать 2 покупку, так как кто купил 2 обычно остаются важно заметить что были удалены 135 тысяч строк без id клиента, результат из-за них может быть смещен. Удержание считается только по покупке без суммы и оптовик и тот кто купил немного считаются одинаково, а для бизнеса приносят разный доход
